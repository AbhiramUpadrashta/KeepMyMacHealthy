# KeepMyMacHealthy

Free, open-source Mac care by **Bubbles Aro**: one-click Smart Care, Cleanup, Protection, Performance, an app Uninstaller & Updater, My Clutter (large files, duplicates, similar photos), Space Lens, a live Health Monitor in the menu bar and a file Shredder.

**Download:** https://bubbles.foo.ng/KeepMyMacHealthy/ · [Releases](https://github.com/AbhiramUpadrashta/KeepMyMacHealthy/releases)

- Everything it removes goes to the Trash first (except Trash contents and the Shredder), so you can undo.
- Asks for your password only for system maintenance tasks, through macOS's own prompt.
- Offers to move itself into Applications on first launch, and updates itself (Ed25519-signed releases).

Requires macOS 14 or later. Build: `bash build.sh`. MIT License.
